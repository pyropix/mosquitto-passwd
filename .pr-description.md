## ⚠️ Breaking Changes

1. **Container User**: Now runs as UID/GID 1000 instead of root
   - Generated files owned by UID 1000
   - May require ownership changes: `sudo chown -R $USER:$USER ./passwd`
   - Or use: `docker run --user $(id -u):$(id -g) ...`

2. **Publish Scripts**: Require environment variables instead of hardcoded credentials
   - Must set `DOCKER_USERNAME` and `DOCKER_PASSWORD`
   - Interactive login removed for security

3. **Username Validation**: Invalid usernames now rejected
   - Path traversal attempts blocked
   - Special characters not allowed
   - Empty usernames rejected

## 📝 Migration Guide

### For Users

**File Permissions:**
If you need to access generated files:
```bash
# Option 1: Change ownership
sudo chown -R $USER:$USER ./passwd

# Option 2: Run with your UID
docker run --user $(id -u):$(id -g) -v ${pwd}/passwd:/passwd burkhardm/mosquitto-passwd:latest
```

**Custom Password Length:**
```bash
docker run -e PASSWORD_LENGTH=64 -v ${pwd}/passwd:/passwd burkhardm/mosquitto-passwd:latest
```

### For Maintainers

**Publishing Images:**
```bash
export DOCKER_USERNAME="your-username"
export DOCKER_PASSWORD="your-password"
./publish.sh
```

**Building Locally:**
```bash
# New unified script
./build.sh --platforms linux/amd64 --load

# Old scripts still work but show warnings
./docker_build.sh
```
